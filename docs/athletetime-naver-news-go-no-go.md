- 결정일: 2026-07-26
- 대상 PR: `#55`
- 현재 결정: **꺼진 상태로 병합 GO / 수동 시험 조건부 GO / 자동 실행 NO-GO**

## 한눈에 보는 결정

| 범위 | 결정 | 이유 |
| --- | --- | --- |
| 코드 병합 | GO | 관리자 전용이며 기본 flag가 꺼져 있고 공개 서비스와 분리됨 |
| disabled 상태 배포 | GO | 외부 호출 0, 기존 기능 영향 없음 |
| 14일 수동 시험 | 조건부 GO | 아래 P0 배포·보안·복원 조건을 먼저 완료해야 함 |
| 매일 자동 수집 | NO-GO | 실제 14일 기록과 책임자 승인이 없음 |
| 자동 초안·승인·발행 | NO-GO | 제품 계약상 금지 |

## 확인한 안전 경계

- API 키는 Render 서버 환경변수에서만 읽고 프론트에 전달하지 않는다.
- `NAVER_NEWS_COLLECTOR_ENABLED`가 정확히 `true`가 아니면 외부 호출은 0이다.
- 일일 40회·월 800회 한도는 PostgreSQL에 누적돼 재시작과 다중 인스턴스에도 유지된다.
- 동시에 누른 요청은 성공·실패 모두 한 실행 결과를 공유한다.
- 기사 본문·description·HTML·원본 응답을 저장하지 않는다.
- 발견 후보는 원출처 확인 전 편성할 수 없다.
- 편성 연결은 issue, source, post를 자동 생성하지 않는다.
- 미성년자 관련 가능성과 선정적 제목은 관리자 경고를 남긴다.
- 관리자 route는 인증과 CSRF가 필요하며 공개 초기 번들에서 분리됐다.
- 중지할 때 collector flag만 꺼도 기록 검색·커뮤니티·매거진은 계속 동작한다.

1. `GO-MANUAL`: 수동 발견만 계속한다.
2. `REVISE`: query profile이나 검토 규칙을 바꾸고 7일 다시 시험한다.
3. `STOP`: flag를 끄고 보존·정리 정책만 수행한다.
4. `GO-DAILY`: 모든 P0와 14일 기준을 충족하고 책임자가 PR에 명시적으로 승인한
   경우에만 별도 자동 실행 PR을 시작한다.

현재 선택은 `GO-MANUAL`이며, P0 전에는 collector를 켜지 않는다.
