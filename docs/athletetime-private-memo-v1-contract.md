# 개인 메모 v1 안전 계약

## 상태

이 문서는 개인 메모를 실제로 열기 전의 출시 경계다. 현재 서비스에는 개인 메모 저장소, API, 화면, 암호화 키가 아직 없다.

아래의 기능 정책 수치와 활성화 판단은 서비스 소유자 승인이 필요한 제안이며, 승인 전에는 feature flag를 켜거나 운영 환경에 키·스키마·경로를 추가하지 않는다. 다만 공개 데이터와 개인 메모를 분리하는 안전 경계는 승인 여부와 무관하게 유지한다.

## v1의 목적과 범위

개인 메모는 로그인한 사용자가 자기 생각을 짧은 텍스트로 적는 계정 전용 공간이다. 공개 기록을 정정하거나, 선수 신원을 확인하거나, 팀 명단을 관리하는 기능이 아니다.

v1은 제목 80자 이하와 본문 12,000자 이하의 텍스트만 다룬다. 목록은 최신 수정순으로 보며, 검색·공유·추천·링크 미리보기·AI 분석은 제공하지 않는다.

## 고정 안전 경계

1. 제목과 본문은 암호화된 값으로만 저장한다. 평문 제목·본문·미리보기는 데이터베이스, 로그, 분석 이벤트, 오류 보고, 캐시, 관리자 도구에 남기지 않는다.
2. 계정 소유자만 자신의 메모를 만들고, 읽고, 수정하고, 삭제하고, 내보낼 수 있다. 다른 계정과 관리자 요청은 메모 존재 여부를 알 수 없다.
3. 제안된 최근 재인증 10분 창은 메모의 목록·읽기·쓰기·복구·내보내기 전에 요구한다. 이 시간은 서비스 소유자 승인 전에는 실제 활성화하지 않는다.
4. 제안된 삭제 후 30일 복구 기간에는 휴지통에서만 되돌릴 수 있고, 만료 뒤에는 복구하지 않는다. 보관 기간과 백업 만료는 서비스 소유자 승인 전에는 실제 활성화하지 않는다.
5. 메모 응답은 `Cache-Control: no-store`를 사용하며, 브라우저 저장소·공유 링크·공개 URL에 본문이나 제목을 남기지 않는다.
6. v1은 첨부 없음이다. 사진·파일·음성·외부 링크 미리보기는 다음 별도 심사 전까지 열지 않는다.
7. 비회원은 메모 요청에 `401`을 받고, 최근 재인증이 없으면 `403 RECENT_AUTH_REQUIRED`를 받는다. 타인·없는 메모·삭제된 활성 메모는 모두 같은 `404 MEMO_NOT_FOUND`를 받는다. 수정 버전 충돌만 `409 MEMO_VERSION_CONFLICT`를 쓴다.
8. 오류 응답과 로그에는 제목, 본문, 소유자, 메모 존재 여부의 단서를 넣지 않는다.

## v1에서 절대 연결하지 않는 대상

개인 메모는 공개 기록과 분리한다. 다음 값과 경로는 메모의 입력·저장·응답·관리 화면에서 모두 금지한다.

| 금지 대상 | 이유 |
| --- | --- |
| `athleteKey`, `recordId`, `sourceId` | 공개 기록 또는 선수 신원과 개인 메모를 자동 연결하지 않는다. |
| `attachment`, `Cloudinary`, `multipart` | v1에는 파일·사진·공개 업로드 경로가 없다. |
| 공개 업로드 URL, 임시 다운로드 URL | 메모 내용이나 파일을 URL로 노출하지 않는다. |
| 운영자 본문 열람, 관리자 검색, 고객지원 전달 | 운영 도구는 메모 내용에 접근하지 않는다. |
| 팀·대회·종목·출처·정정 티켓 | 개인 메모를 공개 서비스의 우회 인덱스로 만들지 않는다. |

## 제안 API 계약

이 경로는 구현 계약일 뿐, 문서 작성만으로 공개하거나 배포하지 않는다.

| 메서드 | 경로 | 목적 |
| --- | --- | --- |
| `POST` | `/api/auth/re-authenticate` | 비밀번호를 다시 확인해 짧은 메모 접근 창을 만든다. |
| `GET`, `POST` | `/api/private-memos` | 본인 목록을 보거나 메모를 만든다. |
| `GET`, `PATCH`, `DELETE` | `/api/private-memos/:id` | 본인 메모를 읽고, 수정하고, 휴지통으로 보낸다. |
| `POST` | `/api/private-memos/:id/restore` | 복구 기간 안의 본인 메모를 되돌린다. |
| `GET` | `/api/private-memos/export` | 본인 메모를 안전한 다운로드 응답으로 내보낸다. |

모든 경로는 인증과 최근 재인증을 다시 확인하고, 로그인 쿠키 요청에는 기존 CSRF 방어를 적용한다. bearer 토큰만으로 메모 본문을 읽는 경로는 만들지 않는다.

## 제안 상태 전이

```text
없음 -> 활성 메모 -> 휴지통 -> 영구 삭제
                 ^         |
                 |---------|
                   30일 안 복구
```

각 수정은 버전 번호를 확인한다. 현재 버전과 다른 수정 요청은 `409 MEMO_VERSION_CONFLICT`로 끝내며, 서버는 제목이나 본문을 되돌려 주지 않는다.

## 화면 문구

- `나만 볼 수 있는 개인 메모예요.`
- `공용 기기라면 끝나고 로그아웃하세요.`
- `30일 안에는 휴지통에서 되돌릴 수 있어요.`

다음 표현은 사용하지 않는다: "종단간 암호화", "운영자가 절대 볼 수 없음", "공식 기록 연동", "AI가 기록을 분석함".

## 출시 보류와 승인 기준

다음 중 하나라도 빠지면 feature flag는 계속 꺼 둔다.

1. 운영 환경의 전용 암호화 키와 복구 절차를 서로 다른 담당자가 확인한다.
2. 최근 재인증 무효화, 소유자 범위, 동일 404, CSRF, 무로그, 내보내기, 삭제 만료를 자동·수동 검증한다.
3. 공개 팀 통계·기록 검색·데이터 권리 요청·관리 도구의 응답에 개인 메모 필드가 없음을 확인한다.
4. 서비스 소유자가 재인증 시간, 복구 기간, 백업 보관 기간, 계정 삭제 처리, 비상 접근 원칙을 서면으로 승인한다.

승인 전에는 이 문서가 개인 메모를 사용할 수 있다는 안내나 개인정보 처리방침의 약속으로 쓰이지 않는다.
