# Historical: AthleteTime 공개 채팅 검증 보류 기록

> **상태**: 과거 검증 기록이다. 현재 채팅은 공개하지 않으며 이 문서는 운영 런북이 아니다.
> 과거의 `scripts/chat-persona-smoke.js`는 운영·스테이징에 실행하지 않는다.
> **현재 스모크**: 채팅 준비 화면이 보이고 `/api/chat/*`와 `/ws/chat`이 `503` 및 `no-store`로 닫히는지만 확인한다.

## 당시 확인한 흐름

과거에는 익명 닉네임, 메시지 발신, 신고, 자동 블라인드가 동작하는지를 여러 페르소나로 확인했다. 이 확인은 기능이 작동한다는 증거일 뿐, 안전하게 공개할 수 있다는 승인은 아니었다.

## 이후 발견한 공개 차단 사유

브라우저가 제공한 `userId`와 신고 키를 서버가 신뢰해 다계정·키 변조로 신고 누적과 메시지 작성자 판별을 조작할 수 있었다. 또한 Origin 검증, 연결·발신 속도 제한, 서버 측 메시지 한도가 충분하지 않았다. 따라서 현재 제품에서는 채팅이 닫혀 있다.

## 재개 시 검증 원칙

새로 승인된 설계가 생기기 전에는 과거 검증 절차나 엔드포인트를 재사용하지 않는다. 재개 시에는 서버 발급 세션, 조작 방지 신고, Origin·속도·용량 제한, 보존·삭제 정책을 포함한 새 테스트 계획을 작성하고 별도 환경에서만 검증한다.
